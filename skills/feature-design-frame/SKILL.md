# Frame

Follow the [shared agreement and persistence rules](../../workflows/feature-design.md#shared-agreement-and-persistence-rules). This skill grants no permissions or role changes.

1. Read project instructions and existing feature context. Inspect only relevant sources first.
2. Clarify who needs what, why, and how success will be observed.
3. Establish scope, non-goals, constraints, existing system context, and significant unknowns.
4. Ask only questions that affect the next decision. Label other unknowns without blocking discussion.
5. At meaningful progress, propose updates to the overview under the shared persistence rules.

Read the [overview template](../../templates/feature/overview.md) only when drafting. Prefer existing project conventions; do not generate the full artifact bundle upfront.
